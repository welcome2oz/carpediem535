# Hull Suite 봇 콘솔 (HTML 한 파일)

Hull Suite 자동매매 봇(①+C+D, 바이비트)의 기록·로그·설정을 브라우저 한 화면에서 보는 **HTML 파일 하나**입니다.
서버·설치·파이썬이 필요 없고, 더블클릭으로 엽니다. 봇의 매매 판단·주문 코드는 건드리지 않습니다.

## 사용 방법

1. `hull-bot-console.html`을 아무 곳에나 저장합니다(봇 폴더 안도 괜찮음).
2. **크롬 또는 엣지**로 엽니다(더블클릭 → 기본 브라우저가 다르면 우클릭 › 연결 프로그램).
3. **봇 폴더 선택** → bot.py가 있는 폴더를 고르고, "파일 수정 허용"을 묻으면 허용합니다.
4. 다음부터는 열 때 **다시 연결** 버튼만 누르면 됩니다(브라우저 보안상 매번 한 번 클릭 필요).

## 할 수 있는 것

| 영역 | 기능 |
|---|---|
| 운영 현황 | 모의·데모·테스트넷·실계정별 마지막 봇 로그 시각, 기록 건수, 최근 기록 한 줄. 3분 안에 로그가 갱신됐으면 "로그 갱신 중" |
| 신규 진입 멈춤 | 스위치로 봇 폴더의 `STOP` 파일 생성/삭제 |
| 매매 기록 | `journal_<모드>.csv`를 최신순 표로, 검색(예: 청산, BTCUSDT) |
| 봇 로그 | `logs/bot_<모드>.log` 마지막 300줄 |
| 상태 파일 | `state_*.json`, `paper_account.json` |
| 설정 | `config.json` 편집. 저장 전 JSON 형식·`leverage` 10 이하·`stop_pct` 0~1·`mode` 값을 검사하고 이전 파일은 `config.json.bak`으로 보관 |

현황·로그·상태는 15초마다 자동 갱신됩니다. 휴대폰 폭에서도 깨지지 않지만, 폴더 접근은 PC의 크롬/엣지에서만 됩니다.

## 할 수 없는 것 (브라우저 보안 제한)

- **봇 시작·정지, 신호 확인은 bat 파일로** 합니다. 웹페이지는 PC의 프로그램을 실행할 수 없습니다.
  화면의 각 모드 카드에 실행할 파일(`run_paper.bat` 등)이 적혀 있고, 오늘 신호는 `check_signal.bat`입니다.
- "로그 갱신 중"은 로그 파일 수정 시각으로 추정한 것이라, 봇이 실제로 켜져 있는지 확실하지 않습니다.
- 파이어폭스·사파리는 폴더 접근 기능이 없어 동작하지 않습니다.

## 보안

- 파일을 이 PC 밖으로 보내지 않습니다(외부 통신 코드 없음).
- `.env`는 읽지 않습니다. 읽는 파일은 위 표의 것뿐이고, 쓰는 파일은 `STOP`, `config.json`, `config.json.bak`뿐입니다.
- 엑셀로 기록 파일을 열어 두면 읽지 못할 수 있습니다. 그때는 엑셀을 닫고 새로고침하세요.

## 점검

```bash
node test_console.mjs
```

브라우저 안의 가짜 봇 폴더로 다음을 확인합니다(Chromium 141에서 통과).
- 쉼표·따옴표가 든 CSV를 최신순으로 표시하고 검색하는지
- 로그·상태 파일을 보여 주고 `.env`는 보이지 않는지
- STOP 파일 생성/삭제
- 잘못된 설정은 거부하고, 올바른 설정은 저장하면서 백업을 남기는지

실행에는 playwright가 필요합니다.
