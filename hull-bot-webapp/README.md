# Hull Suite 봇 웹 콘솔

Hull Suite 자동매매 봇(①+C+D, 바이비트)을 명령창·bat 파일 대신 **브라우저 한 화면**에서
다루기 위한 웹 콘솔입니다. 봇처럼 파이썬 표준 라이브러리만 쓰므로 따로 설치할 것이 없습니다.

봇의 매매 판단·주문 코드는 **건드리지 않습니다.** 콘솔은 봇 README에 적힌 실행 방법
(`python bot.py --mode <모드> [--decide-now]`, `check_signal.bat`, `STOP` 파일)과
파일(`config.json`, `journal_<모드>.csv`, `logs\bot_<모드>.log`, `state_*.json`,
`paper_account.json`)만 사용합니다.

## 설치 · 실행

1. 이 폴더의 `webapp.py`, `webapp.html`, `run_web.bat`을 **봇 폴더(bot.py가 있는 곳)** 에 복사합니다.
2. `run_web.bat` 더블클릭 → 브라우저에서 `http://127.0.0.1:8765`가 열립니다.
3. 끄려면 콘솔 창에서 Ctrl+C. **여기서 시작한 봇도 함께 멈춥니다**(보유 포지션·거래소 손절 주문은 남음).

봇 폴더가 다른 곳에 있으면 `BOT_DIR` 환경변수로, 포트를 바꾸려면 `WEB_PORT`로 지정합니다.

## 화면

| 영역 | 기능 |
|---|---|
| 봇 실행 | 모의·데모·테스트넷·실계정 카드별 시작/정지, 실행 상태·PID·마지막 봇 로그 시각. 실계정은 `LIVE`를 입력해야 시작. 모의·데모·테스트넷은 "지금 바로 판단"(`--decide-now`) 선택 가능 |
| 신규 진입 멈춤 | 스위치 하나로 봇 폴더의 `STOP` 파일 생성/삭제 |
| 오늘 신호 확인 | `check_signal.bat` 실행 결과(신호, 펀딩비 7일 평균, 예상 수량·손절가) 표시 |
| 매매 기록 | `journal_<모드>.csv`를 최신순 표로 |
| 봇 로그 / 콘솔 출력 | `logs\bot_<모드>.log` / `logs\console_<모드>.log`(웹 콘솔로 시작한 봇의 화면 출력) 마지막 300줄 |
| 상태 파일 | `state_*.json`, `paper_account.json` |
| 설정 | `config.json` 편집. 저장 전 JSON 형식, `leverage` 10 이하, `stop_pct` 0~1, `mode` 값을 검사하고 이전 파일은 `config.json.bak`으로 보관 |

상태는 5초, 기록·로그는 15초마다 자동으로 갱신됩니다. 휴대폰 화면 폭에서도 깨지지 않습니다.

## 안전장치

- **이 PC 안에서만 접속**: `127.0.0.1`에만 열립니다. 같은 와이파이의 다른 기기에서도 접속되지 않습니다.
- **다른 웹사이트의 요청 차단**: 실행할 때마다 새 토큰을 만들어 페이지에만 넣고, 모든 요청에서 토큰과 Host 헤더를 검사합니다
  (악성 사이트가 몰래 `localhost`로 "실계정 시작" 요청을 보내는 것을 막음).
- **`.env`는 절대 읽거나 보여주지 않습니다.** 파일 경로에 들어가는 모드 값은 `paper/demo/testnet/live`만 허용합니다.
- **중복 실행 거부**: 같은 모드의 봇을 두 번 시작할 수 없습니다. 다만 bat 파일 등 **다른 곳에서 켠 봇은 알 수 없으므로**,
  봇 로그가 3분 안에 갱신됐는데 콘솔에서는 정지로 보이면 "다른 곳에서 실행 중일 수 있음"으로 표시합니다. 이때는 시작하지 마세요.
- 정지는 Ctrl+C와 같은 신호를 보내고, 15초 안에 끝나지 않으면 강제 종료합니다.

## 알아둘 한계

- 웹 콘솔 창을 X로 닫거나 PC가 비정상 종료되면 여기서 시작한 봇이 추적되지 않은 채 남을 수 있습니다.
  다시 열었을 때 "다른 곳에서 실행 중일 수 있음"이 보이면 작업 관리자에서 `python.exe`(bot.py)를 확인하세요.
- `run_live.bat`의 확인 절차는 콘솔의 `LIVE` 입력으로 대신합니다(봇에 표준입력으로 `LIVE`를 넘김).
  `run_live.bat`에 다른 동작이 더 있다면 알려 주세요. 이 콘솔에 맞춰 반영하겠습니다.
- 매매 기록의 열 이름을 모르는 상태로 만들어서, CSV를 그대로 표로 보여줍니다. 손익 합계·자산 그래프가 필요하면 실제 열 이름을 알려 주세요.

## 점검

```bash
python test_webapp.py
```

가짜 `bot.py`로 시작/정지, 실계정 `LIVE` 확인, 중복 실행 거부, STOP 파일, 신호 확인, 설정 검사,
토큰·Host·경로 검사, `.env` 비노출을 확인합니다(Linux Python 3.11에서 통과. 윈도우 전용 동작인
`cmd /c`와 `CTRL_BREAK_EVENT` 경로는 이 PC에서 처음 실행할 때 확인 필요).
